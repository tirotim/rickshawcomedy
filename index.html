Rick Shaw Comedy versions

Pick a build to open. No password or sign-in — these are static local mockups.

Run ./serve.sh (or python3 -m http.server 8080) from this folder, then open http://localhost:8080/. Do not open index.html directly from Finder (file://) — that can break previews and may trigger unrelated browser prompts.
